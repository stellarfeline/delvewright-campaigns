# 杜恩城堡：导览之旅

> **Requires delve engine 0.25.0 or newer** — last verified with delvec 1.5.0 on Minecraft Java 1.21.11.

> *"当心楼梯——左半边早就踩穿了，比咱俩谁来得都早。"*

跟着一个熟门熟路的人，走一遍一座真实的城堡。九处停留，一位导游，没有战斗，没有刷怪：跟着她走大约三十五分钟，四处闲逛就更久些——而从第一分钟起，闲逛就是允许的。

## 这是什么

一行人抵达北面的来路，整座城堡的外观就在眼前。埃尔斯佩思·蒙克里夫在杜恩当了二十年导游；她带你穿过门道、庭院、领主厅和公爵夫人厅、大厅、厨房、王室居室，最后登上城墙步道。在某一处停下时和她说话，你就能听到这间屋子，以及这座城堡六个世纪里的一段往事——年份照直报数，观点当面亮明。谈话结束后，她会走向下一处，等着你。

![北面来路：跨过壕沟、通往城门的桥](media/doune-castle-approach.jpg)

每一扇门都开着。你可以跑到她前面去，独自下到地窖，找到守卫室底下的地牢，或者站进她还没提到的祈祷室。

## 这是一座真实的城堡

杜恩，位于斯特灵，14 世纪末——为奥尔巴尼公爵罗伯特·斯图尔特而建，他治理苏格兰，却始终不曾为王。选中它，是因为它的房间至今带着屋顶保存下来、有据可查；它的布局是一个运转中的家宅，而不是一片入画的废墟；它的几何形状方正规整，足以老老实实地搭建出来。

布局遵循这户人家自己的动线：领主住在自家城门之上，谁进门都逃不过他的眼睛；大厅建在地窖之上，高台紧挨着领主的门；厨房在大厅的另一头，通过两个传菜口供餐；客人住在厨房上方，因为那是任何城堡里最暖的一面墙；守备队守在城门和城墙上。资料来源见 `design/research.md`。

比例为每米 1.5 个方块。第四面楼曾经规划过，却从未建成。

## 开始游玩

```sh
docker run -it -p 25565:25565 -e EULA=TRUE ghcr.io/stellarfeline/delve-doune-castle-tour:latest
```

这是当前版本的秘境。若想固定在某一个确切版本，请改用发布页上的 `:vX.Y.Z` 标签；每个发布都会写明自己的标签。

启动服务器，然后在上方印记所写版本的 Minecraft Java 客户端中：多人游戏 → 直接连接 → `localhost:25565`。

加上 `-e DELVE_RESET_WHEN_EMPTY=90`，那么只要连续 90 秒无人在线，世界就会被丢弃并从镜像重新构建，下一个到来的人会进入一个无人动过的秘境——但这样一来，**每一次**启动都会重置，在一队玩家游玩途中重启容器，就会终结他们这一轮。不加这一项，世界就会保留。下限是 60 秒；低于它，服务器会拒绝启动。
