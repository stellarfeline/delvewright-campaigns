# 哨卫厅

> **Requires delve engine 0.60.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

瓦罗的哨卫厅收着旧日守夜人的像：披甲的死者立在红毯两侧的石台上，每一个都还守在当年睡着的那个岗位。看守人阿玛·斯特雷尔放访客顺着大厅一直走到尽头那扇门，想摸什么都行。这些像不会醒。差不多全都不会。

一个十分钟左右的演示关卡，一到四人。

## 你会遇见

- **阿玛·斯特雷尔**，哨卫厅的看守人，厅里每一尊像她都掸了二十年的灰。她在大厅北头的门房里迎客。

## 职业

- **访客** —— 一把赶路用的剑、一件旅行外套、几块面包。你是来看旧日守夜人的。

## 开始游玩

启动服务器，然后用上方标记所写版本的 Minecraft Java 客户端：多人游戏 → 直接连接 → `localhost:25565`。服务器提示资源包时，请选择接受。

## 给主人：这一关要看什么

这一关用来在游戏里检验"无害的身体会说出自己是什么"（spec-0119）：一个游戏本身认作怪物的种类、伤不了也不会打的身体，站在队伍走得到的地方，被打一下——如果是演员，被右键一下也算——就会用战役写好的一句话回应，显示在打它的那个玩家的动作栏上，只给那一个人看。机器已经证明了这份普查：厅里八个身体，其中六个是游戏认作怪物的种类；四尊像和那位队长，每个都欠着、也都带着"挨打"和"被摸"各一句；铁傀儡带着两句它并不欠的话（游戏在和平难度下会留下铁傀儡）；远处门边那个干瘪的身影一句也不欠，因为打它本身就会触发别的事；每一句话都是以按下去的那个玩家的身份发出的。机器人会走完整个大厅，但什么也不打。机器说不出来的是：这一切**读起来**怎么样。请以访客的身份走一遍，想打什么就照常去打。

1. **把石台上的每一尊像都打一下、右键一下。** 走到队长之前一共有四尊像，红毯两边各两尊。每一尊挨打时说一句，被右键时说另一句，语气各不相同——灰尘、寒冷、一句警告、一句玩笑。这句话在准星那里能不能在消失前读完？你是打一下看到一句就停手，还是会接着试？
2. **这句话现在还没有配声音。** 这一版引擎还没有"被拒绝"的提示音，所以回应只有这一句话。没有声音的一句话，读起来像是像在回应你，还是像游戏没理你？
3. **大厅中段红毯旁边地上站着的那个铁傀儡。** 它也会回应，虽然没有任何规则要求它说话。它的点击范围是不是贴合铁傀儡本身（它比那些像更宽更高）？打在铁傀儡身上任何位置，都能得到它那句话吗？
4. **队长是你往下走时左手边的最后一尊像**，全身铁甲，剑还拔着。走到尽头那扇门之前先打他一下：他会像其他像一样回应。然后继续走到门前：你一到门口，队长就会从石台上走下来朝你过来。这时再打他：他会流血、会还手，而且一句话也不说。在一整厅的雕像之后，他的苏醒读起来像不像一个回报？
5. **靠在尽头门边的那个干瘪身影。** 打它一下：它会猛地从墙上弹开、咔啦作响，然后又靠回去，这一下的回应就是这一击本身。右键它：它是一个角色，所以会弹出它自己简短的对话，而不是一句话。
6. **如果有第二个玩家：** 站在朋友旁边，让他去打一尊像。你应该什么也看不到；只有打像的那个人能看到那句话。

走到尽头那扇门，关卡就结束了。
