# 军械库

> **Requires delve engine 0.49.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

![格雷霍特俯瞰](media/greyholt-from-above.jpg)

格雷霍特是荒原路上的一座石砌哨所，艾德·芬威克在这里守了三十个冬天。如今她终于要下山去山谷了，新来的守卫沿着荒原路上山接哨。哨位跟着它的剑走，那把剑就在军械库的架子上。

一个十分钟左右的演示关卡，一到四人。没有战斗。

## 你会遇见

- **艾德·芬威克**，格雷霍特哨所的守哨人。开春化冻起，她的行囊就搁在门边了。

## 职业

- **新守卫** —— 你自己的弓，几支箭，几块面包。你沿荒原路上山，来这里站岗。

## 开始游玩

启动服务器，然后用上方标记所写版本的 Minecraft Java 客户端：多人游戏 → 直接连接 → `localhost:25565`。服务器提示资源包时，请选择接受。

## 给主人：这一关要看什么

这一关用来在游戏里检验"物品放在场景该放的地方"（spec-0111）：物品挂在、立在场景里本该放它的地方，冒险模式下的玩家用游戏本身的操作把它取走，却拿不走、也打不坏盛放它的东西。机器已经证明了盛物件普查：军械库里五个盛物件——三个盔甲架、一个荧光物品展示框、一个箱子——每个都装着东西；每个实体盛物件要么挂在实心方块上，要么立在地板上；每个旁边都有一个能站人、够得着、中间没有遮挡的位置；引擎生成它们时带上了它自己掌管的那些标记。机器人已经把剑从架子上取了下来。机器说不出来的是：这些东西**读起来**怎么样。请以新守卫的身份走一遍，遇到想拿的东西就照常去拿。

1. **架子上那把剑是你可以拿走的。** 艾德告诉你，哨位跟着它的剑走，剑在架子上，让你拿出来。她没说怎么拿。从她身后那扇门走进军械库。不用人提醒，你能不能明白：左手墙边那排架子中间那个盔甲架上的剑，是你可以从架子上取下来的？
2. **你会点盔甲架的哪里。** 请留意你第一下点在每个盔甲架的什么位置，以及第一下有没有把东西取下来。游戏按点击的高度决定取哪个栏位：头盔只有点在头上才会取下；拿在手里的东西，点在架子其他任何位置都能取下。
3. **头盔、盾牌和地图都能拿走。** 离门最近的架子戴着守卫头盔；离窗最近的架子副手上挂着一面盾牌；门所在那面墙的内侧、远离架子的那一边，有一个荧光物品展示框，里面放着荒原路地图。每样东西都应该能进到你的物品栏：头盔和盾牌是点一下架子；地图是打一下展示框，它会掉在你脚边。右键点展示框只会转动地图，什么也拿不到。
4. **没有任何办法打坏或带走盛物件。** 打一打盔甲架，空的和没空的都试；展示框空了以后再打它；试着往空架子上挂东西，或往空展示框里放东西。每个架子和展示框都应该原地不动，也什么都放不上去。如果有展示框或盔甲架本身进了你的物品栏，请记下来。
5. **窗下的箱子里只有箭，别的什么都没有。** 打开它。窗下一箱箭，读起来像不像军械库的一部分？对一个背着弓的人来说，这说得通吗？

把剑带到院子里交给艾德，关卡就结束了。
