# 两把钥匙

> **Requires delve engine 0.41.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

马罗比的羊毛行会会堂把契书锁在一间有两把锁的库房里。按行会最老的规矩，守库人的钥匙挂在账房，书记的钥匙放在档案室，而守门的管事哪一把都不能拿。新任会长们天亮就要宣誓，契书今晚得拿出来。

一个十分钟左右的演示关卡，为两人设计，一个人也能通关。没有战斗。

## 你会遇见

- **赫斯基斯·马尔**，替羊毛行会会堂守了二十二年库房门，却从没碰过它的钥匙。

## 职业

- **熟手** —— 你自己的提灯和晚饭。行会今晚派你到会堂来帮管事。

## 开始游玩

启动服务器，然后用上方标记所写版本的 Minecraft Java 客户端：多人游戏 → 直接连接 → `localhost:25565`。服务器提示资源包时，请选择接受。能拉上第二个人最好。

## 给主人：这一关要看什么

这一关用来在游戏里检验队伍共享进度（spec-0018）：整个队伍的进度是同一件事，两个人可以在两个房间里各做半件事，任务道具只交到动手拿它的那个人手上，而一个人也照样能通关。机器已经在服务器上证明：只转开一把锁，库房不开；由两个不同的玩家各转一把，库房才开（这道"合流"的双人 PackTest）。机器人也一个人把整关走完了，每把钥匙都握在手里去开它自己的锁。机器说不出的是两个人分头干活是什么感觉；它也没看过钥匙落进一个人的背包、而另一个人没有——机器人只有一个。请两个人玩一遍，一人一侧；再一个人玩一遍。

1. **两人各走一侧。** 赫斯基斯说完以后，一人从东门进账房，另一人从西门进档案室。每一侧各有一把钥匙。不用赫斯基斯再说一遍，会堂本身能不能让人看明白：这件事是要分成两半做的？
2. **钥匙只给拿它的人。** 一个人拿到钥匙时，去看另一个人的背包：里面应该没有钥匙。只有点击的那个人会拿到。
3. **一把锁只认握在手里的它自己的钥匙。** 分别空着手、钥匙只放在背包里没拿在手上、手里拿着另一侧的钥匙，去点一把锁。每种情况都应该只出现一行提示，说那把钥匙不在你手上，锁也不会转。把对的钥匙握在主手上，锁才转得开。
4. **一把锁不够。** 第一把锁转开以后，库房门仍然闩着，赫斯基斯也还没有开门的话可说。要等两把锁都转开，他才会提出拉开门闩。
5. **队伍一起前进。** 一个人转开一把锁时，两个人都应该看到同样的日志提示。没转第一把锁的那个人，也可以去告诉赫斯基斯两把都转开了，门会为两个人一起打开。
6. **钥匙可以转手。** 把钥匙扔在地上，让另一个人捡起来，用它去转锁。
7. **一个人也能通关。** 自己再玩一遍：两把钥匙都去取，两把锁都转开，再把契书拿出来。

把契书交给赫斯基斯，这一关就结束了。
