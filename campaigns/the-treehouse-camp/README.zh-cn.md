# 树屋营地

> **Requires delve engine 0.38.0 or newer** — last verified with delvec 1.11.0 on Minecraft Java 1.21.11.

一场写给几位客人的轻松短途冒险：一个森林部族把家安在四棵巨树上，树与树之间拉着绳桥，树干上挂着绳梯。一年里只有一个夜晚，家家户户都把灯笼挂出来。

## 故事开始之前

大林是一片古老的巨树森林，每棵树的根部都宽得能在树根之间盖起一座房子。大林氏族就住在这里，离地而居：四棵巨树大致围成一个方形，每棵树的树干上，在离林地很高的地方都绕着建了一座屋子，屋与屋之间拉着绳桥。

你们是氏族请来的客人。傍晚时分，你们来到其中一棵巨树的树根之间。这天正好是氏族一年一度的灯笼夜，一个男孩在绳梯下面等着你们。

## 你们会遇到的人

**托比**：氏族里的一个男孩，被派下来接你们。他每天都爬那架梯子，也会老老实实告诉你，他怕它。

**奥鲁**：氏族的头领，守着最高那座屋子里的火塘。灯笼夜里有她的身影，比谁记得的年头都长。

**内芙**：织工。她的织机摆在一棵早就没了树冠的巨树平顶上。手脚麻利，做事实在，总是在忙。

**赫塞尔**：营地里年纪最大的人，榨坚果、管种子。动作慢，脾气好，谁愿意听他说话，他都高兴。

![从南面望去的营地，右边是瞭望树](media/camp-from-the-south.jpg)

## 这是一场什么样的冒险

在冒险模式里走一走、爬一爬。营地里没有任何敌意。

**爬梯子。** 绳梯挂在树皮上。走到梯子跟前，按住前进键（或跳跃键）就能往上爬；松开就往下滑；按住潜行键可以停在原地。

**过桥。** 每个平台、每座桥都有栏杆。住在不同高度的屋子之间，桥会顺着木板台阶上上下下。

**林地。** 万一落到地上，桥下的小路都点着灯，每条路都能走回第一架梯子下的林间空地。

**什么都不用带。** 客人该有的东西都会给你：一双好靴子，一点吃的。

## 开始游玩

一条命令就能把营地架起来。然后在上面版本标记所写版本的 Minecraft Java 客户端里：多人游戏 → 直接连接 → `localhost:25565`：

```sh
docker run -d --name delve -p 25565:25565 -v delve-data:/data \
  -e EULA=TRUE ghcr.io/stellarfeline/delve-the-treehouse-camp:latest
```

这是当前版本。想固定在某个确切版本，就去发布页面取 `:vX.Y.Z` 标签，每次发布都写明了自己的标签。加入时客户端会提示加载资源包（角色皮肤和中文文本），请接受。想从头再来：先执行 `docker rm -f delve && docker volume rm delve-data`，再运行同一条命令。
