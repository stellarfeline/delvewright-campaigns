# 潮汐磨坊

> **Requires delve engine 0.41.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

盐沼湾的潮汐磨坊已经好些年没有磨坊主了，可每逢退潮，水轮照样转，照样带着下面那条干水道里的三道闸板一起一落。从海堤上到磨坊院子，只有沿这条水道走一条路，一道闸板接一道闸板地过去，一道比一道快。

一个约十分钟的演示关卡，一到四人。没有战斗。

## 职业

- **搬运工**——你把一袋袋货从船上扛到磨坊。脚上一双踩湿石头的靴子，兜里几块爬坡时吃的面包。

## 怎么玩

启动服务器，然后用版本与上方标记一致的 Minecraft Java 版客户端：多人游戏 → 直接连接 → `localhost:25565`。服务器提示资源包时选择接受。

## 给验收者：看什么

这一关用来在游戏里看定时闸门（spec-0016 §4）。水道是一条笔直的、两边有高墙的走道，三道闸板横在路上，各按各的节奏升起、落下；闸板落下时人在底下，当场就死。机器已经证明：哪一道闸板都绕不过去（走道两侧封死，每道闸板是两段水道之间唯一的通路）；路线上三道闸板都要过；每一道都给步行的人留了公平的一段周期，在这段时间里动身就过得去——第一、二、三道分别是 60%、43%、23%；每段水道里都有离下一道闸板至少五格远、站着就能看清它的地方；在 PackTest 里，每道闸板都按节奏升落，落下时只认得出正站在它底下的人（PackTest 里的替身玩家死不了，所以“砸死”这一下没有经过机器实走）。机器人从水道一路过了三道闸板走到院子里，每道都等到窗口才过，从没在闸板落下时站在底下。机器说不了的是：玩家动身之前，能不能先看懂节奏；越收越紧的窗口，玩起来是一步步学会的，还是像掷硬币。

1. **第一道闸板，一进来就在正前方。** 一块三格宽、三格高的木板，上面压着一根深色横梁。升起四秒，落下两秒。你会先停下来看一轮再走，还是直接撞上去？站在最下面那段水道里，看得出这块板会动吗？
2. **算错了会怎样。** 至少有一次，故意在闸板落下时站在底下。应该当场死掉，并在你到过的最后一段水道里复活（第一次是在水道脚下）。死得明白是闸板干的吗？复活的位置公道吗？
3. **第二道闸板。** 升起两秒半，落下两秒半。有了第一道的经验，窗口变短会不会让人觉得是顺理成章的下一步？
4. **第三道闸板。** 升起一秒半，落下三秒半，只比引擎允许的下限宽一点点。靠观察还判断得过来吗，还是感觉全凭运气？
5. **闸板之间的水道。** 每段八格长，够你退到离下一道闸板五格远的地方。这点地方够不够从容地看完一整轮？
6. **多人一起。** 不止一个人时，试试一起过和一个一个过。只有几个人同时挤在一块闸板底下才会出的问题，请记下来。

水道尽头通向磨坊院子，走进院子就结束了。
