# 集结阁

> **Requires delve engine 0.45.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

一百年前，哈罗盖特的征召兵在山腹里的大厅集合，开拔出征，没有一个人回来。如今每到黄昏，他们仍会在大厅地面上列队。修这座大厅的镇长把所有出路都封死，不让亡兵离开：上阁楼的楼梯、下地窖的井口、库房的楼梯，还有地窖梯子顶上的格栅。亡兵倒下，前三道就会打开；格栅要靠大厅里的一根拉杆掀开。

今年镇公所派你下到大厅。击倒集结的亡兵，从地窖里取出征召名册，放进保存名单的阁楼，让这支征召兵终于可以解散。

一个十到二十分钟的演示关卡，一到四人。有一场短战斗。

## 职业

- **大厅守望者** —— 一把剑、一面盾、一件甲和几块面包。镇公所为山腹里的大厅设一名守卫，今年轮到你。

## 开始游玩

启动服务器，然后用上方标记所写版本的 Minecraft Java 客户端：多人游戏 → 直接连接 → `localhost:25565`。服务器提示资源包时，请选择接受。

## 给主人：这一关要看什么

这是这一关的第二轮。上一轮发现的四个问题，这次改了三个：

- 地窖井口和库房楼梯井上的盖子原来是一片铁栅，人会从中间掉下去。现在两处都换成了平铺在地面上、关着的铁活板门。机器已经在任何剧情节点之前，让一个身体站上每一处的每一个点，确认都站得住。
- 梯子洞口上那一根孤零零的铁栅，换成了一块平铺在大厅地面上的铁活板门。
- 原来充当绞盘的磨石去掉了。格栅后面三格、靠南墙的地上有一根拉杆，拉它就能掀开格栅。

第四个问题这一轮**没有**修：一走进阁楼，"把名册放进阁楼"就立刻完成。这一点请不要测。

阁楼梯顶没有改动，仍是横在梯顶过道上的铁栅。请以大厅守望者的身份走一遍。

1. **盖子站得住。** 战斗之前，任务日志会带你逐一去看每条被封的路。走到阁楼梯脚下附近大厅地面上的那个井口，再到库房里楼梯井上的那个盖子，分别走上活板门站一会儿。你应该稳稳站在上面。它们读起来像"剧情以后会打开的盖子"，而不是普通地板吗？
2. **梯子的盖板。** 井口和库房门之间地面上的格栅，现在是盖在梯子洞口上的一块铁活板门。它读起来像盖住一条下去的路吗？之后从地窖爬木柱旁的梯子：应该停在最上面一级，盖板就在头顶。这感觉像"从上面关住的路"，而不是 bug 吗？
3. **战斗。** 四处都看过之后，亡兵会在大厅地面上列队。击倒他们。最后一个倒下的那一刻，阁楼梯的铁栅和两处井盖同时打开，梯子的盖板不动。
4. **拉杆。** 从打开的井口跳进地窖，从角落的箱子里取出名册，试着爬一下梯子。然后绕远路回来：走楼梯井上到库房，再穿过库房门回到大厅。盖板后面靠南墙的地上这时会有一根拉杆，拉下它。盖板掀开了吗？这根拉杆读起来像是开盖板的机关吗？拉杆是在你从下面试过梯子之后才放上的，之前并不在那里。
5. **然后去阁楼。** 爬上阁楼梯，走进阁楼，这一关就在你进门的那一刻结束（就是上面那个没修的问题）。
