# 集结阁

> **Requires delve engine 0.45.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

一百年前，哈罗盖特的征召兵在山腹里的大厅集合，开拔出征，没有一个人回来。如今每到黄昏，他们仍会在大厅地面上列队。修这座大厅的镇长把所有出路都用铁栅封死，不让亡兵离开：上阁楼的楼梯、下地窖的井口、库房的楼梯，还有地窖梯子顶上的格栅。亡兵倒下，铁栅才会升起。

今年镇公所派你下到大厅。击倒集结的亡兵，从地窖里取出征召名册，放进保存名单的阁楼，让这支征召兵终于可以解散。

一个十到二十分钟的演示关卡，一到四人。有一场短战斗。

## 职业

- **大厅守望者** —— 一把剑、一面盾、一件甲和几块面包。镇公所为山腹里的大厅设一名守卫，今年轮到你。

## 开始游玩

启动服务器，然后用上方标记所写版本的 Minecraft Java 客户端：多人游戏 → 直接连接 → `localhost:25565`。服务器提示资源包时，请选择接受。

## 给主人：这一关要看什么

这一关用来在游戏里检验"带门禁的连接建成时就是关着的"（spec-0107）。大厅的每一条出路从世界加载的那一刻起就用方块封着，每一道铁栅在打开它的那个剧情节点升起。机器已经证明：四道铁栅在世界加载时都立着；剧情要关住的三条路（阁楼梯、井口、库房楼梯）没有任何一条能靠走、跳、摔、游绕过去；这一关能打通。机器说不出来的是：这些铁栅**读起来**怎么样。请以大厅守望者的身份走一遍。

1. **每道铁栅都读得出"剧情以后会打开这里"。** 战斗之前，任务日志会带你逐一去看每条被封的路：
   - 爬上大厅后墙那道石梯：梯顶通往阁楼的过道被铁栅堵满；
   - 石梯脚下附近大厅地面上的井口：一片铁栅盖在通往黑暗的竖井上；
   - 磨石旁边、离井口几步远的地面格栅：一格铁栅，底下是梯子最上面一级；
   - 穿过敞开的门进库房：一片铁栅盖在楼梯井上。

   每一处读起来像"暂时关着的门"，而不是墙或装饰吗？
2. **战斗结束时三道打开，一道不动。** 四处都看过之后，亡兵会在大厅地面上列队。击倒他们。最后一个倒下的那一刻，阁楼梯的铁栅、井口和库房楼梯的铁栅应该同时升起，格栅不动。三道读起来像是在那一刻打开的吗？格栅不动读起来像是有意为之吗？
3. **格栅下梯子的最上一级是一个"到此为止"。** 从打开的井口跳进地窖，从角落的箱子里取出名册，然后爬木柱旁的梯子。它应该把你送到最上面一级就停住，格栅就在头顶。这感觉像"从上面关住的路"，还是像个 bug？
4. **绕远路，再从上面拉开格栅。** 梯子不通，出路是走楼梯井上到库房，再穿过库房门回到大厅。在格栅旁的磨石处拉开格栅。格栅是在那一刻升起的吗？之后梯子读起来像进地窖的近路吗？
5. **然后去阁楼。** 爬上已经打开的阁楼梯，走进阁楼放下名册，这一关就结束了。
