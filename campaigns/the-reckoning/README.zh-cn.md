# 清算

> **Requires delve engine 0.46.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

温德湖每年从水闸放一次水，湖底的清算屋就能干上一天。守屋人伊索尔德·马罗要趁湖水回来之前，把这座屋子清算一遍。今年，她请了几个外人先进屋走一趟：去看唤铃，去看牢房里的那个人，去看台子上的账簿——每一样，觉得怎么做对，就怎么做。

一个十分钟左右的演示关卡，一到四人。没有战斗。

## 你会遇见

- **伊索尔德·马罗**，清算屋的守屋人，跟她母亲当年一样。是她叫你们来的，她就在屋子最里面的祭坛旁等着。
- **托宾·里夫**，被锁在门廊旁边的牢房里。他家欠了债，屋子把他扣在这里，一直扣到清算。

## 职业

- **见证者** —— 伊索尔德的召信，一盏提灯。清算之前由你走遍清算屋，你在屋里做了什么，守屋人就清算什么。

## 开始游玩

启动服务器，然后用上方标记所写版本的 Minecraft Java 客户端：多人游戏 → 直接连接 → `localhost:25565`。服务器提示资源包时，请选择接受。

## 给主人：这一关要看什么

这一关用来在游戏里检验"结局读的是整局"（spec-0108）。屋里有三件事，做不做都由你：敲门廊里的唤铃；放走托宾，或者让他锁着；把账簿放进台子旁边的火盆烧掉。伊索尔德按这三件事一起清算这座屋子，结局有三个：账簿烧了，**屋子烧掉**；账簿没烧、但你敲了铃或放了托宾，**屋子留下**；两样都没做，**屋子被淹**。请多玩几遍，每遍做不一样的选择。

1. **守屋人的话有没有说中你在每一件事上做了什么？** 你让伊索尔德清算时，她依次说唤铃、托宾、账簿，每件一句，每句都应该准确说出你做了什么——敲没敲、放没放、烧没烧。镜头回来以后，每件事还有一句收尾，说它最后怎样了（谷里的人在泥滩上还是在家里；托宾回了家、仍锁着，还是被伊索尔德放走）。
2. **每个结局是不是顺着你的选择来的？** 她的裁断取决于"做了几件好事"和"烧没烧账簿"：烧了账簿，不管别的怎样，屋子都会烧掉；敲了铃或放了托宾，屋子留下；两样都没做，屋子被淹。请留意裁断读起来是你选择的后果，还是来得没有道理。
3. **镜头回来时，眼前的景象像不像那个结局？**
   - *屋子烧掉*：你（和伊索尔德）站在门外的泥滩上，拱门后面内殿的地上在烧。
   - *屋子留下*：你站在内殿里，祭坛上的一排蜡烛点亮了。
   - *屋子被淹*：你站在内殿里，湖水漫过地面，正从拱门往外流。
