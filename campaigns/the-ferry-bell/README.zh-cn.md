# 渡船之铃

> **Requires delve engine 0.42.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

![从东南方看沙岸、码头和渡船屋](media/panorama.jpg)

雨天的下午，一片沙岸。渡船停在海峡对岸，只有敲响渡口的钟，它才会开过来。钟在码头尽头的渡船屋里，门从外面闩着。内尔·加罗守这口钟守了三十年，可她不肯一个人去敲：前三回钟一响，就有死人从水湾里爬上来，爬到对岸的沙嘴上。

单人，十分钟左右。你以**旅行者**的身份到来，带着一根船钩、一件油布衣和一块面包头。

**内尔·加罗**是渡口看守，站在码头口的雨里，一条胳膊揣在外衣里。

## 怎么玩

先启动服务器，再用上面那行标注的 Minecraft Java 版本进游戏：多人游戏 → 直接连接 → `localhost:25565`。请接受服务器的资源包：内尔的长相和中文文本都在里面。把客户端语言设成简体中文，就能用中文玩。

![你到达时看到的景象](media/arrival.jpg)

## 这一关是做什么的

这是"玩家看得懂的引导"的演示关：一个从没在 Minecraft 里按过键的人，在任何时候都能知道下一步做什么、按哪个键，而关卡里没有任何发光、悬浮或指路的标记。每一步要么就在上一步结束的地方一眼能看到，要么在开始时用一句提示说清楚。每一步的标题都以手上要做的那个动作开头，中英文都一样。某一类操作第一次要用到时，内尔会告诉你按哪个键——是你自己客户端里绑定的那个键。

## 看点

中英文各玩一遍。没有任何一步会出现标记。

1. **开场先教会右键，再要你点第一下。** 一开局，第一个目标出现（*与渡船看守交谈* / *Talk to the ferry-keeper*），紧接着聊天栏里是内尔的一句话：*想和岸上的人说话，走近后按……即可。* 这句话里的键名，读起来是不是**你自己的**按键（默认是"鼠标右键"；把"使用物品"改绑到别的键，它就跟着变）？这句话是不是在你还没点过任何东西之前就到了？
2. **第二句教学跟着告示一起来。** *读渡船告示*出现时，第二句话告诉你：告示牌、拉杆和钟，也都是按同一个键。一个只点过人的玩家，看到这句会不会知道去点那块牌子？
3. **每一步都能从脚下看出来。** 站在内尔身边，能看到码头口东侧柱子上的告示吗？站在告示前，能看到沿码头往外十六格、渡船屋门边甲板上的拉杆吗？只有一步带了提示——钟，它在屋里，被门挡住了（*在渡船屋里，立在屋子正中的钟架上。*）。有没有哪一步，不靠标记就找不到？
4. **拉杆一看就是唯一该拉的东西。** 它装在甲板上，离栏杆最后一根桩子一格，就在闩着的门旁。它看起来像门闩的拉杆、而且是那里唯一能拉的东西吗？（第一次构建时它装在栏杆上、夹在栏杆的桩子中间，见下面的"拒绝记录"。）
5. **水对岸的敌人先集结，再朝你来。** 敲响钟。三个死人从水湾对岸的沙嘴上爬上来，透过渡船屋东墙的窄窗就能看见，大约十五格远。第三句教学告诉你攻击键。它们看起来是不是先在对岸聚拢，再沿着岸边绕过来找你，而不是凭空出现在你身边？
6. **这个地方本身。** 它像不像雨中的渡口：一片沙滩，一道带栏杆的码头，码头尽头水上一间小木屋，水湾对岸围着篱笆、晾渔网的沙嘴？

如果在战斗中死了，你会在码头上复活，那几个死人还站在原地。

## 拒绝记录

这一关第一次构建时，门闩拉杆装在码头栏杆上，夹在栏杆的云杉木栅栏桩中间。下面每一次都是整个战役加上一处标明的改动，跑一遍 `delvec build`；`transcripts/` 里是原样记录。

**拉杆夹在栏杆桩中间**（`transcripts/lever-on-the-rail.txt`，退出码 3）。栏杆把它挡住了：从告示到拉杆的视线，先碰到了下一根桩子。

```
DW0863 [error] build: on the critical path, the `interact` act `obj/draw-the-bolt` cannot be found by the party: from `obj/read-the-notice`'s cell ([8214, 64, 8209]) its target [8208, 64, 8198] is 12.6 blocks away and hidden: the line is stopped first at [8208, 64, 8199]. …
```

**同样的位置，加一句提示**（`transcripts/lever-on-the-rail-with-a-hint.txt`，退出码 0）。加上提示 *On the jetty's west rail, a few steps out from the shore.* 之后，构建走到了"同类孪生"检查，并且通过：拉杆不是栅栏，所以夹在栅栏桩中间的拉杆，并不算混在同类里。

```
DW1017 binding: 3 pressable(s) — 3 alone within 3.0 blocks, 0 marked; 0 refused among 0 twin cell(s)
```

**用栏杆本身的方块做拉杆**（`transcripts/a-pole-lever-among-its-posts.txt`，退出码 3）。在加了提示的那次构建上，把拉杆换成栏杆自己的方块——一根要拉的云杉木栅栏桩：

```
DW1017 [error] build: `interact` objective `obj/draw-the-bolt` is pressed at [8208, 64, 8198] on a `spruce_fence`, and 6 more `spruce_fence` stand within the click's reach (3.0 blocks) of it: … Nothing tells the party which one to press. …
```

之后拉杆从栏杆上挪到了门边的甲板上，告示那里看得见它，构建通过。

## 这一关没有展示的

- **告示是空白的。** 作为道具的告示牌上没有字，点它时文字出现在聊天栏里。
- **雨。** 上面的渲染图没有画雨、云和雨雾；游戏里从头到尾一直在下雨。
- **死人是僵尸**——这片岸边的死人，雨让它们在白天也不会被晒燃。
