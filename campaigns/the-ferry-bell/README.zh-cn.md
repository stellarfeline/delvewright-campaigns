# 渡船之铃

> **Requires delve engine 0.56.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

![从东南方看沙岸、码头和渡船屋](media/panorama.jpg)

雨天的下午，一片沙岸。渡船停在海峡对岸，只有敲响渡口的钟，它才会开过来。钟在码头尽头的渡船屋里，门从外面闩着。内尔·加罗守这口钟守了三十年，可她不肯一个人去敲：前三回钟一响，就有死人从水湾里爬上来，爬到对岸的沙嘴上。

一到四人，十分钟左右。你以**旅行者**的身份到来，带着一根船钩、一件油布衣和一块面包头——和每个人一样，还有一只指南针和一本日志。

**内尔·加罗**是渡口看守，站在码头脚下的雨里，一条胳膊揣在外衣里。

## 怎么玩

先启动服务器，再用上面那行标注的 Minecraft Java 版本进游戏：多人游戏 → 直接连接 → `localhost:25565`。请接受服务器的资源包：内尔的长相和中文文本都在里面。

![从岸上看码头和渡船屋](media/jetty.jpg)

## 这一关是做什么的

这是"玩家跟得上的引导"的演示关。每个玩家都带着一只指南针，它指向一件还没做完的事；对着它按右键，会弹出所有未完成的事，让你挑一件来跟。一根看上去不像门闩的拉杆，有人走近时会发光。每个人手里还有一本日志：指南针怎么用、内尔的笔记、未完成的事（你正在跟的那件带标记），以及划掉的已完成的事。

## 看点

最好两个人一起玩，有几条需要第二个人。

1. **指南针的菜单。** 和内尔说话，说你来敲钟。两件事同时出现：*读渡口告示牌* 和 *敲响渡船钟*，聊天栏里各出现一行它的标题和提示（告示牌：“码头口的柱子上，木板路的右手边”），并响一声叮。光凭这行提示，你找得到它吗？手持指南针按右键。会不会弹出一张未完成事项的列表，你正在追踪的那件前面有 ◆？选另一件。指针会不会转过去，聊天栏会不会显示"正在追踪：……"？
2. **两只指南针，两个方向。** 站在内尔身边，一个人从列表里挑钟，另一个人跟告示牌。告示牌就在旁边几步、码头口；钟在码头正前方的尽头、渡船屋里。两根指针是不是指向不同的方向？
3. **拉杆只在走近时发光。** 渡船屋的门是闩着的。从岸上看，门闩拉杆就是门旁甲板上一根普通的拉杆。沿着码头往外走。是不是只有走到最后一段甲板、离它六格以内时，它才亮起金色的轮廓——往回走又熄灭？这道光是不是让人一看就知道"就是这根"？拉下它：门开了没有？屋里的钟不发光：它看上去还像不像一口钟？
4. **日志按顺序读。** 打开日志（对它按右键）。顺序是不是：先一页讲指南针，再两页 *渡口看守的笔记*（第一页里的使用键是你自己绑定的那个键），然后每件未完成的事一页、带提示、你在跟的那件有 ◆ 标记，最后是划掉的已完成的事？读完告示牌后再打开一次：告示牌是不是挪到了划掉的那几页，钟是不是还在未完成的事里？
5. **掉线重连，或者中途加入。** 在码头上断开再连回来，或者让第二个人在对话之后才加入。重连的人手里的日志是不是和原来一样？后加入的人拿到的日志，是不是已经写好了哪些没做、哪些做完了？
6. **结束时每根指针都在打转。** 敲响钟；三个死人在对岸沙嘴上列队，然后沿着岸边绕过来。最后一件事做完时，是不是每只指南针的指针都在打转、每本日志都只剩划掉的页？
7. **进场的那句话。** 刚进场时聊天栏里有一句关于木桶的话，伴着木桶合上的声音。岸上的木桶都空着：读完这句，你会不会去翻它们，还是直接往码头走？

如果在战斗中死了，你会在码头上复活，那几个死人还站在原地。

## 机器记录

发布的构建（`delvec build` 退出码 0，跑两次，逐字节相同，221 个文件）：所有引导绑定行都写在英文版 README 里。

- PackTest：42 项必需测试全部通过，其中包括七项引导测试——指南针（指向、菜单按钮、挑选、打转、补发）、指向人物的指南针、指向战斗的指南针、拉杆的高亮（关着时不亮、范围内亮、范围外不亮），以及日志的页面、丢掉的日志和新加入玩家的日志。
- 机器人关键路径：通过——对话、门闩拉杆、告示牌、钟、战斗——战斗中一次脚本化死亡后在码头复活并重新接战；内尔转身面向玩家被验证了 15 次；进场时那句关于木桶的话和它的声音都到了。
- 服务器写出的世界与引擎的模型在每个比较的格子上都一致（17895 格），只有服务器自己重新推导的那几类方块除外。

## 这一关没有展示的

- **告示牌是空白的。** 引擎还写不了摆放好的牌子上的字，点它时文字出现在聊天栏里。
- **雨。** 上面的渲染图没有画雨、云和雨雾；游戏里从头到尾一直在下雨。
- **空木桶。** 一进场，聊天栏里会有一句话说这片岸上的木桶都是空的：只要有容器里什么都没有，引擎就要求说这一句。
- **死人是僵尸**——这片岸边的死人，雨让它们在白天也不会被晒燃。
- **图里的光。** 这里没有一张图画出了高亮；它读起来如何，只能在游戏里判断。
