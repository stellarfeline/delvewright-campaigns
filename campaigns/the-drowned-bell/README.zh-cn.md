# 沉钟

> **需要 delve 引擎 `delvec` ≥ 0.1.0 · Minecraft 1.21.11 · 战役格式 0.8**

*1–4 人的魂系 delve，约 2–3 小时。它打算杀你。*

晚钟堡的钟,从前每天两次把潮水敲退,露出干的堤道,香客们就从上面走过去。后来有人
把钟砍了下来,沉进堡自己的水窖里。戍卫们在各自的岗位上空了。海不再听了。

一位摆渡妇趁着低潮,把你放在了坟场海岸上。

爬上这座堡。把沉下去的东西拽起来。敲响它。

## 这是一个什么样的 delve

三条规矩,这座堡三条都守:

- **死是用来学的。** 死很便宜,而且本来就该发生。在篝火边休整,它会替你记住你走到
  了哪里。它不会替你守住地盘:这座堡已经放出来咬过你的东西,你站起来的时候,它们
  也会站起来。
- **近路是挣来的。** 每一条远路的尽头,都有一道从另一侧闩死的门。从背后掀开它,
  你就再也不必走那一趟。你越懂这座堡,它折叠得越紧。
- **话只说一遍。** 警告只来一次——以你看见过的某个东西的形式,或者以某人一边扫地
  一边随口提起的一句话的形式。进门之前先抬头。迈步之前,先看那东西走完一整圈。

没有肝度,没有合成,没有升级。你这辈子会拥有的一切,头两分钟就全发给你了。

## 篝火

三处篝火,它们就是全部的安全网。坐下之后可以**休整并存档**——记住你的进度,补满
炖菜,同时让这座堡重新上膛——也可以**只存档**,如果你并不想惊醒什么。你会学会自己
刚才想选的到底是哪一个。

## 你会遇到的人

**摆渡妇**把船拖上潮线,谁也催不动她。她渡过比你糟得多的客人。她至今还按着那个
再也不来的潮汐钟点摇橹,而她想在自己的胳膊废掉之前,再听一次钟声。

**司事**在院子对面的礼拜堂里,扫一座他再也点不着的炉膛。他招呼你的样子,像是几年
前就在等你。他给出警告的口气,和别人谈论天气一样。

**坟场戍卫**跪在坟茔之间,剑尖插进土里。它不巡逻,也不追人。它两侧的地又宽又空,
绕开它走,不需要你付出任何代价。

这是一个真的选择。这不是提示。

## 职业

在海岸的火堆边挑一个。四个都是发全的——甲、武器,外加一份**炉边炖菜**,每次休整
都会补满。

- **末代戍卫** —— 剑,盾,和一份让敌人先犯错的耐心。这座堡就是你这种打法的人砌起
  来的,所以别人看装饰的地方,你读得出杀机。三份炖菜,因为距离就是你的语言,而你
  对自己的仁慈是定量的。
- **钟楼射手** —— 你的手艺是在还活着的海岸边、朝钟楼上的海鸥练出来的。这里没有
  什么东西扛得住被先看见,而你最擅长先看见。两份炖菜;你盘算着用不上更多。
- **提灯人** —— 从前有香客的时候,你提着灯走在他们前头。黑暗里杀人的东西,多半从
  头到尾都摆在明处。火把要插在你已经清干净的角落里,好让后面的人不必再清第二遍。
- **掘城人** —— 每座堡都是两座:图纸上那座,和水与失修在底下悄悄砌的那座。你干的
  是下面那座的活。一块石头丢进对的水洼,替你按你的规矩挑起过许多架。

## 怎么玩

先构建 delve,再连本地服务器:

```sh
# 简体中文
delvec build campaigns/the-drowned-bell -o validation/delve-output --lang zh-cn

# English
delvec build campaigns/the-drowned-bell -o validation/delve-output
```

```sh
EULA=TRUE docker compose -f validation/compose.yaml --profile play up
```

用原版 **1.21.11** 客户端加入。天是黑的,雷是响的,这是故意的。

想边玩边留下试玩笔记(游戏内 `/trigger dw.note`):

```sh
CREATOR_NAME=<你的 minecraft 名字> \
  EULA=TRUE docker compose -f validation/compose.yaml --profile playtest up
```
