# 维斯珀堡

> **Requires delve engine 0.34.0 or newer** — last verified with delvec 1.6.0 on Minecraft Java 1.21.11.
> (上一行是版本印记,不翻译:它声明本战役需要的引擎版本、最近一次验证所用的 delvec 版本,以及本秘境运行所需的 Minecraft Java 版本。)

> *"守望的朋友们。在下哈尔瓦德·德雷爵士,誓守国王之门。是哪一扇,我已记不起了。"*

一座魂系城堡秘境,留给一小队受雇的刀剑——雨中峭壁上的一座哥特式城堡,一口裂了却仍在低鸣的钟,一个忘了为何守望却仍在守望的宫廷,以及从堤道到王座之间的五堆火。

## 前情

十年前,维斯珀堡的大钟最后一次敲响。从那以后城门再没开过。卫兵照旧巡逻,国王照旧坐在王座上,可他们谁也说不出自己守着的是什么。

堤道脚下,路边神龛旁,有个女人守着一堆火。她贴出告示招募受雇的刀剑,条件说得明明白白:那座城不为任何人开门,所以得你们自己去把它打开。她管城堡叫"那座城",管钟叫"她";你问她什么,她多半回你一件差事;不知道的事,她就说不知道。

你们揭了那张告示。天色已暮,雨正下着,城堡就在头顶的峭壁上,每一道门都关着。

## 你会遇见的人

**塔姆辛·赫斯克**——城外最后一堆火的守火人。务实,火和面包给得大方,答案给得吝啬。她说自己从前在城里提过守钟人的灯。她说,你们只需要知道这么多。

**哈尔瓦德·德雷爵士**——一位誓守国王之门的老骑士。他已经记不起是哪一扇门了,于是每天早上挑一扇,站在那里守着。彬彬有礼,不紧不慢,只要有人肯同他说话就很高兴;他怕什么,也会照直说出来。他会向你打听国王的消息。你告诉他什么,是要紧的。

**佩拉姆修士**——朝圣者,货郎,也许还是个修士;这一点他自己也拿不准了。他把死人的东西卖回给活人,只收蜡脂;每做一笔买卖都要先来一句谁也没听过的"俗话说"。他讲的故事一回一个样,价钱却从来不变。

**宫廷**——门口的看门人,巡逻的卫兵,王座上的国王。他们都还在自己的位置上,却没有一个能告诉你为什么。

而城堡本身还记得。碎钟的残片落在哪里,哪里就会有一声回响:回响持续的那一会儿,雨停了,天空变回那最后一个早晨晴朗的正午,当时站在屋里的人又站回原处,说着他们当时说过的话。然后雨又落下来,他们便不见了。

## 这是怎样一座秘境

魂系,冒险模式。落到手上,是这样的:

**火堆。**从堤道到王座,一共五堆。到了火边,你可以*歇息*:伤养好了,肚子填饱了,装备修好了,守夜药剂也重新装满,倒下之后就从这里回来——可你之前放倒的那些寻常敌人,也都会回来。你也可以*只是烤烤火*:这堆火成为你回来的地方,别的什么都不变。

**死亡。**你会在上一堆火边醒来。你身上的蜡脂——城里唯一的钱——留在你倒下的地方。走回去捡起来。还没捡到就又死了一次,它就没了。蜡脂靠放倒城里的杂兵挣来,谁下的手就归谁,所以丢了的钱袋是能再挣回来的。

**走回去。**从火堆走到下一场硬仗的路都不长;从另一侧打开的门,会一直开着。你越熟悉这座城,它就越往回折叠到你身边。

**大路之外。**城里每一片地方都有不必去的去处:一间卫兵室,一座棱堡,礼拜堂后的一方院子,一道门后的花园。有的藏着箱子。有的藏着一场可以绕过去的战斗——其中几场是精英,打倒后会掉下他们拿来跟你打的那件兵器或盔甲。大路上的一切都用不着它们。能找到附魔书,也有铁砧可以把它们用上。

**相信眼睛,然后再看一眼。**不是每面墙都是墙,也不是每只箱子都是箱子。这座城在耍花样之前,总会先给个提示。

**什么都不必带。**开始时从四种职业里挑一种,这个职业该带的东西都会发到你手上。没有挖矿,没有合成,没有练级。

**你说的话算数。**这座城会两次要你们做出决定。两个答案都是真的:你说什么,会改变你往里走时看到的东西,也会改变故事的结局。结局一共四个,没有一个被标成好结局。

## 开玩

一条命令,城堡就开起来了——然后在多人游戏里直连 `localhost:25565`:

```sh
docker run -d --name delve -p 25565:25565 -v delve-data:/data \
  -e EULA=TRUE ghcr.io/stellarfeline/delve-vesperhold:latest
```

这是当前版本的秘境。想把它定死在某一个版本上——同一个世界、同一份台词,永远不变——就改用发布页上的 `:vX.Y.Z` 标签,每个发布页都会写明自己的。进服时客户端会提示启用资源包(人物皮肤),接受即可。每个版本的发布页附带完整更新日志。想重头再来:`docker rm -f delve && docker volume rm delve-data`,然后重跑同一条命令。

一小时左右,是一支队伍第一次通关的时间:走完主线,沿途四处看看。

## 已知局限

- 维斯珀堡里没有人会游泳。城堡底下那口灰色的井,谁下去谁就回不来;井边那圈井栏,就是为了把你挡在外面。
- 铁砧用着用着就会坏,这是铁砧的本性,城里也没有东西能修好它们。每一座都只能指望用上寥寥几次。
