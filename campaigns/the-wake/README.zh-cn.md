# 守灵

> **Requires delve engine 0.55.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

城堡外墙脚下，有一座潮水一天退两回的小岛，岛上是一片墓地。雷恩·阿什洛为城堡看了一辈子潮，最后也是在看潮时淹死的。她的族人从正午起就站在坟墓之间等着。退潮时分，一行陌生人把她的遗体抬上岸来。按这片墓地的老规矩，谁抬着遗体走上这条路，她最后归到哪里，就由谁来说。

一个十五分钟左右的演示关卡，一到四人。没有战斗。

## 你会遇见

- **哈利斯·阿什洛**，她的哥哥。自从遗体被抬上来，他就一直守着岸边那堆火，一次也没抬头往墓地那边看过。
- **塞奇**，守墓人。这片墓地里的每一座坟，都是她亲手挖的。

## 职业

- **抬棺人** —— 上山的路上你抬着棺板的前头，到现在也没人说要换你。一盏守灵灯，一件丧服，几块面包。
- **吹芦人** —— 下葬时墓地要听一声号，那支号在你手里。
- **捧花的孩子** —— 花总是年纪小的人来捧，这里也没人问过你多大。

## 开始游玩

启动服务器，然后用上方标记所写版本的 Minecraft Java 客户端：多人游戏 → 直接连接 → `localhost:25565`。服务器提示资源包时，请选择接受。

## 给主人：这一关要看什么

这一关用来在游戏里检验"演出"（spec-0014）：引擎按时间轴召出角色、让他们走过墓地、再把他们收走；一段仪式用一串定时出现的台词和声音讲出来；镜头会切走去拍这些场面。机器已经证明：每一段行走，走的那个身体都有路可走；时间轴的每一步按顺序落地；火堆边的两个回答各自通向自己的结局；机器人把两个回答都完整打通了。机器说不出来的是：这些东西**看起来**怎么样。每一遍大约十五分钟；请走两遍，第二遍在火堆边给出另一个回答。

1. **墓地在你身后站满了人。** 先去火堆边跟哥哥说话。等你转身往墓地走，钟声响起，送葬的人在大约七秒里一个接一个出现。看上去像是墓地慢慢站满了人，还是像一个个身体凭空蹦出来？
2. **身体在走路。** 守墓人开始念悼词时，有三个人同时走动：提灯人从城门走下来，孩子从石墙边走进来，守墓人沿着那排坟走过去。请看他们的腿和朝向：每个人是不是在走路、脸朝着前进的方向、停在该停的地方，没有滑行、没有跳格、也没有穿过墓碑？
3. **镜头。** 你的视角会被切走三次：走到黑旗下时一个从高处降下来的远景；悼词期间一个跟着提灯人平移的镜头；最后还有一个。移动的身体是否整段都在画面里？远景里你的同伴是不是站在你们刚才站的地方？镜头切回来时你是不是还在原地？
4. **悼词的节奏。** 悼词是三句话加两声钟，前后大约十三秒。每一句出现后，你来得及读完，下一句才到吗？
5. **遗体。** 死者是一个披着棕色裹尸布的盔甲架，头顶写着她的名字。它读起来像被抬着的遗体，还是像一个在走路的盔甲架？这一条最想听你的判断。
6. **两遍的最后一段路。** 最后，遗体会从黑旗下走到你让她去的地方。两遍都应该从黑旗下出发、一路走完，起步时没有跳一下。两段路里较长的那段，几乎走完整片墓地。
7. **面孔和目光。** 守墓人和哥哥都有自己的脸，谁走近就转头看谁。送葬的人不转头。这些有没有哪里破坏了葬礼的气氛？

关卡里没有任何东西会伤到你；水边那排石头会把你挡在海外面。
