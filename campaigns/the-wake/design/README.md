# The Wake — design reference

**Nothing in this directory is approved.** This is the set put to the design
gate, and the gate has not been held: no one has confirmed it. When it is
confirmed, that fact is recorded here and this sentence goes. Until then, do not
author against these as approved art and do not cite them as a confirmed design.

Every image is a single full-frame view, drawn in one series: view 1 from the
prompt alone, and every later one anchored on view 1's interaction id under the
same style note. The style note is `../design/style-note.txt`, held constant
across the series. Each `.jpg` has its `.json` sidecar beside it carrying the
prompt, the style note, the resolved frame and the anchor — which is what makes
a view re-issuable with one word changed instead of only replaceable.

## What is NOT drawn, and is owed before the gate can be held as the page describes

The page asks for **every scene with both a near view and a far view**. Six
images is a bounded set, chosen because the provider bills per image returned
and the owner was not present to authorise the spend. These places have no
concept art of their own and are represented only inside the map views:
`node/coast-road`, `node/fork-stone`, `node/high-road`, `node/drowned-road`,
`node/barrow-shoulder`. The three scenes above have a near view and no far view.

Author from the image, judge against it, present every choice beside it.
