# 税关之路

*一段关于「留神」的短程秘境。*

通往晚钟城塞的潮路，是唯一一条不必涉水的内陆通道，而城塞至今仍在收路费。它要的不是钱。
从坟丘海岸到蓄水池底下的宝库之间，一共有三道税关，每一道都是一件老实的机关：
台阶里的一块石板、竖井壁上的一个槽孔、壁龛里的一口箱子。
它们都会在动手之前，先让你看清自己的构造。这条路上没有东西藏着——
这就是整套安排，也是从来没人事后抱怨得起来的原因。

走得仔细，你会带着城塞的路税文书离开，两只手也都还在。

## 你会遇见的人

**税关匠奥德温**照管这条路。他管的不是那笔钱，而是这条**路**本身：
校准的踏板、通畅的槽孔、上过油的拉杆。他谈起这些机关的口气，
像一个好工头谈一支从没迟到过的班组；你问什么他都答，答得很长，而且不收费。
比起收到钱，他更愿意被人读懂。

他自己不走这条路。

## 职业

开局挑一个，装备直接发给你，没有任何刷取内容。

- **守路人** —— 铁甲与盾。箭矢打在铁上，你只管走。
- **潮行者** —— 轻皮甲、一盏提灯、两颗苹果。你读懂路，而不是被路吃掉。

这是一关**短小的教学关卡**。它是为一个从没见过 Delvewright 陷阱的人准备的，
只玩一遍，玩完就知道一个陷阱该怎么读。

## 开始游玩

先构建秘境，再启动服务器：

```sh
delvec build campaigns/the-toll-road -o validation/delve-output --lang zh-cn
EULA=TRUE docker compose -f validation/compose.yaml --profile play up
```

去掉 `--lang zh-cn` 即为英文版本。

连接 `localhost` 即可。难度由世界本身决定，不要去改服务器设置——秘境自带规则封印。
