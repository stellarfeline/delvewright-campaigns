# 收费古道

> **Requires delve engine 0.41.0 or newer** — last verified with delvec 1.13.0 on Minecraft Java 1.21.11.

收费的守卫一代人以前就离开了哈罗隘口，什么也没带走。如今穿过隘口的路不再收钱，可凿进两侧墙里的库房还是守卫走时的样子，机关一个没拆；隘口顶端的收费横杆也还落着。

一个约十五分钟的演示关卡，一到四人。没有战斗。

## 职业

- **车夫**——你赶车运货，常走这道隘口。身上一件外套，一把割绳的刀，几块路上吃的面包。

## 怎么玩

启动服务器，然后用版本与上方标记一致的 Minecraft Java 版客户端：多人游戏 → 直接连接 → `localhost:25565`。服务器提示资源包时选择接受。

## 给验收者：看什么

这一关用来在游戏里看陷阱（spec-0011）：引擎能做的每一种陷阱，各守着路边一间库房；每间带机关的库房，门口旁边的路墙上都有一根解除机关的拉杆。机器已经证明：每个陷阱的触发方块都在它该在的格子上；每道箭雨的射孔看得见它覆盖的每一格，而且射得够慢，箭一响就动身的玩家走得出来；塌顶之后宝箱仍然够得着；每个陷阱都能从它的 PackTest 里触发。机器人沿路走到头、升起了收费横杆，没进任何一间库房。机器说不了的是：玩家踩上去之前，看不看得出这是陷阱；拉杆能不能教会人怎么应对。请从隘口脚下往顶端，按顺序把库房走一遍，每间先不碰拉杆试一次，再拉了拉杆试一次。

1. **收费亭，右手（东侧）第一间。** 一格宽的门口铺着一块石质压力板。踩上去，亭里的铃会响，动作栏出一行字，此外什么也不发生。先遇到一块无害的压力板，会不会让人对后面的压力板留个心眼？板后的木桶里有一面盾牌；留意你会不会想到带着它进下一间。
2. **台阶间，左手（西侧）。** 三级台阶通到一个平台，平台上有一块压力板，后面是木桶。踩板会从台阶上方的孔里连射三轮箭，扫过平台和每一级台阶。站在台阶底下看得见那块板吗？不踩板能不能够到木桶？箭雨来时来不来得及退下台阶？然后拉一下台阶间门口稍往前（朝隘口顶端）那面路墙上的拉杆，再踩一次板：应该不再放箭，拉杆也应该从墙上消失。
3. **飞镖廊，右手。** 一条窄廊从路边拐进去，半路两只绊线钩之间拉着一根绊线，尽头放着木桶。路墙底部开了几个低矮的箭孔，站在路上就能看进廊里。跨过绊线，会从木桶上方顺着廊道连射三轮箭，间隔够你在两轮之间走出去。走进去之前看得见那根线吗？箭孔能不能让你看清廊里的情形？拉杆在廊口稍往回（朝隘口脚下）的路墙上。
4. **宝箱间，左手。** 屋里靠后墙只有一只箱子，它是陷阱箱。一打开，箱前那片鹅卵石屋顶就会化作沙砾塌下来，砸在站在那里的人身上，只塌一次。砖砌屋顶里夹着一块鹅卵石，看得出是警示吗？塌下来之后，还能踩着沙砾够到箱子吗？拉杆在屋门稍往前的路墙上。
5. **拉杆。** 每根拉杆用过之后都应该消失，它管的陷阱从此对全队都不再触发。如果有哪根拉杆点了没反应，或者拉过之后陷阱照样触发，请记下来。

到隘口顶端，用收费横杆旁的绞盘拉杆升起横杆，走过去就结束了。
