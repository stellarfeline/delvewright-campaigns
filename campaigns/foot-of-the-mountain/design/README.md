# Curtain Up in Kelderby — approved design

The approved reference set for this campaign: three views of the whole town and a near and a far view of each of the seven scenes. Author from the image, judge against it, present every choice beside it.

Every image was drawn under one style contract (`style.txt`), each later image anchored on `reference/view1-from-the-sea`; each image's prompt is in `prompts/` and its request, frame and anchor in the sidecar beside it.
